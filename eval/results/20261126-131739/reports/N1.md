# N1：單相浸沒式液冷系統中，冷卻液採逆重力流與順重力流時，晶片溫度、熱阻與 PUE 的差異有多大？

## 結論摘要
在單相浸沒式液冷系統中，採用逆重力流（anti-gravity flow）相較於順重力流（pro-gravity flow），能有效降低晶片外殼溫度與熱阻，並減少整體能源使用效率（PUE） [KB-1][KB-3]。不過，順重力流則在提升系統溫度均勻性與降低系統壓降方面表現較佳 [KB-3]。

## 證據分析
* **晶片溫度與熱阻**：在條件保持一致的情況下，採用逆重力流可將 CPU 外殼溫度（chip case / CPU case temperature）降低 33.8%，並將熱阻降低 55.6% [KB-1][KB-3]。此外，逆重力流亦使 CPU1-2 與 CPU2-2 的局部努塞爾數（Nusselt numbers）分別增加 121.2% 與 157.8% [KB-3]。
* **能源使用效率（PUE）與泵浦功率**：為了維持一致的最高 CPU 溫度，逆重力流可使系統的泵浦功率（pump power）降低 60.8%，進而使系統的 PUE 降低 1.4% [KB-3]。
* **溫度均勻性與壓降（順重力流的優勢）**：相較於逆重力流，順重力流可將浸沒式液冷櫃內的溫度均勻性提升 325%，並減少 9.8% 的系統壓降 [KB-3]，同時能有效緩解 CPU 的熱級聯效應（thermal cascade effect） [KB-4]。

## 限制與建議
* **實驗條件限制**：現有證據主要來自特定的幫浦驅動單相浸沒式液冷實驗平台（包含多個伺服器機板） [KB-2]，數據是在保持其他條件一致的情況下取得 [KB-3]。
* **後續查證方向**：未來可進一步探討不同冷卻液物性、更大規模的資料中心資料櫃，以及在不同發熱功率密度下，流向對長期運作穩定性與其他流體力學參數的綜合影響。
