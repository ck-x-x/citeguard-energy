# N1：單相浸沒式液冷系統中，冷卻液採逆重力流與順重力流時，晶片溫度、熱阻與 PUE 的差異有多大？

## 結論摘要
在單相浸沒式液冷系統中，與順重力流（pro-gravity flow）相比，採用逆重力流（anti-gravity flow）可顯著降低晶片外殼溫度達 33.8%、熱阻降低 55.6%，並使系統功率使用效率（PUE）降低 1.4% [KB-1][KB-4]。然而，順重力流在改善浸沒式液體機櫃內的溫度均勻性（提升 325%）以及降低系統壓降（減少 9.8%）方面表現較佳 [KB-4]。

## 證據分析
* **晶片溫度與熱阻**：在所有其他條件保持一致的情況下，逆重力流可將 CPU 外殼溫度與熱阻分別降低 33.8% 和 55.6% [KB-4]。
* **局部對流換熱與效率**：逆重力流可使 CPU1-2 與 CPU2-2 的局部努塞爾數（Nusselt numbers）分別增加 121.2% 和 157.8% [KB-4]。為了維持一致的最高 CPU 溫度，逆重力流可使系統泵浦功率減少 60.8%，進而促使系統 PUE 下降 1.4% [KB-4]。
* **溫度均勻性與壓降**：相較之下，順重力流方向能將浸沒式液體機櫃內的溫度均勻性提升 325%，並減少 9.8% 的系統壓降 [KB-4]，同時能有效緩解 CPU 的熱級聯效應 [KB-5]。

## 限制與建議
上述數據來自特定系統層級泵驅動之單相浸沒式液冷實驗平台（包含多個伺服器機板）的研究 [KB-2][KB-4]，其適用條件為保持其他條件一致下的對比結果 [KB-4]。後續研究可進一步查證不同伺服器佈局、不同冷卻液物性及更大規模系統下，流向對長期運作穩定性與經濟效益的綜合影響。
